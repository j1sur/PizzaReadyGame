# PizzaReadyGame

A mobile-friendly pizza shop prototype inspired by the requested colorful isometric style.

## Run it

Open `index.html` in a browser, or enable **Settings → Pages → Deploy from branch → main / root** on GitHub.

## Prototype features

- English UI
- Touch-friendly virtual joystick
- Collect tomatoes from the farm
- Prepare and serve pizzas
- Earn coins
- Hire a worker
- Upgrade the shop

This is a browser prototype. The next step for a true 3D Android game is importing the gameplay into Unity and replacing the placeholder art with original 3D assets.
